# 0.4.10 — Plaisir brand collection

Experience's existing brand-details section now shows the supplied scattered cups, stacked cups and takeaway bag, in a wide photograph followed by two offset images. Story adds a brand-identity section after the proposition with the three menu concepts and two coaster designs. Mobile menus use a contained horizontal scroll gallery, with all designs visible in a row on desktop. Artwork is labelled as illustrative rather than a confirmed menu or price list.

All eight assets have individual editor fields, crop controls and overlay preferences. Overlay defaults off for the new brand artwork so its printed colors stay legible. Existing database content, previous image fields, financial forecasts, hero and hospitality photography remain preserved. Supplied JPEGs are converted to optimized WebP assets.

Validation: npm run check and live route checks. Physical iPhone/Safari testing unavailable.
